# SABAN CREATIVE STUDIO

סטודיו יצירה שיווקית וטכנית עבור **ח. סבן חומרי בניין (1994) בע״מ**.

המערכת בונה מצגות, תסריטי וידאו, פקודות AI, מסכי דלפק ולובי, מאגר מוצרים ומקורות ידע. היא לא ממציאה נתוני צריכה, תקנים או זמני ייבוש.

## ארכיטקטורה בפועל

סביבת ההרצה והפריסה של המוצר היא **TanStack Start** (React, TypeScript, Tailwind, ניתוב קבצים, פונקציות שרת). זו המקבילה כאן ל־App Router ול־Route Handlers: הדפדפן לא קורא לגיליון ולא רואה מפתחות.

```text
ממשק → פונקציית שרת מאומתת → שכבת שירות → Postgres
                                              ↘ Google Apps Script, כשמחובר
```

כל עוד `GOOGLE_APPS_SCRIPT_URL` ו־`GOOGLE_SHEETS_API_KEY` לא הוגדרו, הנתונים נשמרים ב־Postgres (מקומית בתצוגה, Neon בפריסה). המסך מציין זאת במפורש.

## תפקידים

- `ADMIN` — הכל, כולל מחיקת מוצר, שינוי תפקיד וסנכרון גיליון. המשתמש הראשון שנכנס מקבל את התפקיד.
- `EDITOR` — יצירה ועריכה.
- `VIEWER` — קריאה בלבד.

הכניסה היא חשבון אמיתי (Google או X). אין משתמשי הדגמה.

## Google Sheets

1. צרו גיליון.
2. הדביקו את [docs/google-apps-script.gs](docs/google-apps-script.gs) ב־Apps Script המחובר לגיליון.
3. הגדירו מאפיין סקריפט `API_KEY`.
4. פרסמו Web App כ״אני״ ו״כל מי שיש לו את הקישור״.
5. הגדירו בשרת, לא בקוד:

```text
GOOGLE_APPS_SCRIPT_URL=
GOOGLE_SHEETS_API_KEY=
GOOGLE_SPREADSHEET_ID=
GOOGLE_DRIVE_FOLDER_ID=
```

אחר כך, במסך ההגדרות: בדיקת חיבור, ואז סנכרון (מנהל בלבד). הסקריפט נועל כתיבה עם `LockService` ומאשר הצלחה רק אחרי כתיבה.

Drive: אם הוגדר מזהה תיקייה הוא מוצג ככזה. אין העלאת קבצים אוטומטית בלי אסימון Drive. במדיה נשמרות כתובות בלבד.

## בינה מלאכותית

- טקסט: Grok, רק בלחיצה על ״שיפור ניסוח״, עם תקרת אסימונים והנחיה שלא להמציא מפרט.
- תמונה, קובץ וידאו וקריינות קולית: לא מופעלים בממשק, גם אם קיים מפתח.
- Gemini: מוצג כמחובר רק אם `GEMINI_API_KEY` קיים. אין קריאה אוטומטית.

## NotebookLM

אין API מחובר. במסך הידע שומרים קישור למחברת, מסמך שיוצא ממנה, שיוך למוצר וציטוט. בדיקת טענה רצה על הציטוטים השמורים בלבד.
